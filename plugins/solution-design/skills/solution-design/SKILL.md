# 方案设计

## 工作流程

1. 分析需求，设计技术方案
2. 输出包含以下内容的技术方案：

### 方案模板

```markdown
## 需求分析
- 一句话描述核心需求
- 涉及的用户场景

## 影响模块
- 需要修改的模块及文件
- 是否涉及架构选择

## 实现步骤
1. 步骤一：具体做什么、在哪个文件
2. 步骤二：...
3. ...

## 风险点
- 可能踩到的坑
- 需要注意的边界情况

## 影响范围
- 是否影响现有功能
- 是否需要更新文档
```

## 审批

方案输出后等待用户确认，用户回复"通过"或"开始实施"后才进入编码阶段。

## 与 dev-flow 的关系

`solution-design` 是轻量版，只做方案不继续推进。`dev-flow` 是全流程一条龙。
