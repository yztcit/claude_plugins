# 生成提交信息

## 工作方式

1. 查看当前项目的 git 提交历史，学习项目已有的提交风格
2. 查看当前暂存区或未提交的改动内容
3. 按照项目的实际提交习惯生成提交信息：
   - 匹配项目已有的格式（如 `[类型]：描述`、`type: description` 等）
   - 如果是中文项目，描述使用中文
   - 简明扼要，说明做了什么、解决了什么问题
4. 输出提交信息，用户确认后执行 `git commit`

## 常见类型参考

如果项目没有明确规范，参考以下类型标签：
- `feat` — 新功能
- `fix` — Bug 修复
- `refactor` — 重构
- `perf` — 性能优化
- `chore` — 构建/工具/依赖

**关键原则：匹配项目已有风格，不要强行套用模板。**
